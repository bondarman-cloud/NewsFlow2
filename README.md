# NewsFlow2

Автоматический Telegram-публикатор новостей о новых компьютерных комплектующих, мониторах, периферии и ноутбуках.

## Что делает

- собирает новости с официальных ресурсов крупных производителей;
- отбирает только анонсы, релизы и старт продаж компьютерного железа;
- переводит заголовок и краткое содержание на русский язык через Gemini;
- находит и загружает изображение статьи;
- публикует один пост в Telegram раз в час;
- сохраняет базу опубликованных ссылок между GitHub Actions runs.

## GitHub Secrets

Добавьте в `Settings → Secrets and variables → Actions`:

- `BOT_TOKEN`
- `CHANNEL_ID`
- `GEMINI_API_KEY`

Ручной запуск доступен через workflow `Run NewsFlow2 manually`. Автоматический workflow запускается один раз в час.
